# Weather App

A simple weather app built with vanilla JavaScript. Enter a city name to see its current temperature, humidity, and weather conditions, using data from [WeatherAPI](https://www.weatherapi.com/).

## Features

- Search for current weather by city name
- Shows temperature, humidity, and a short description of the conditions
- Handles invalid cities and failed requests

## Built With

- HTML
- CSS
- JavaScript (no frameworks or libraries)
- [WeatherAPI](https://www.weatherapi.com/)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Get a free API key from [weatherapi.com](https://www.weatherapi.com/).
3. Open `script.js` and set your key:
   ```javascript
   const apiKey = "YOUR_API_KEY";
   ```
4. Open `index.html` in your browser.

## Usage

Type a city name into the search box and submit the form to see the current weather.

## Note

Don't commit your real API key to a public repository.
